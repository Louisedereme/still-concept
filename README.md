STILL — version 3.3

Évolutions depuis la v3.2 :
- davantage de blanc et de respiration sur l'ensemble du site ;
- espaces renforcés entre titres, textes, images et sections ;
- typographie légèrement réduite et interlignage augmenté ;
- composition Collections plus éditoriale, avec séparation plus nette des deux phrases ;
- pages Origami et Traverse plus aérées ;
- footer conservé discret, avec davantage de vide avant son apparition ;
- ajustements responsive pour préserver l'équilibre sur mobile.


## v3.4
